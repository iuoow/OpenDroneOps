# ADR 0010: Batched Realtime Rendering

- 状态：Accepted
- 日期：2026-07-26

## 背景

设备遥测频率可能高于浏览器需要的视觉更新频率。逐消息更新全局 Store、地图和组件会增加 INP、主线程长任务和内存压力。

## 决策

WebSocket 事件进入缓冲和标准化层，Telemetry 可按设备合并，并按 animation frame 或固定低频批量更新 UI。告警和命令事件保持可恢复事件语义。

## 结果

降低渲染压力；用户看到的是最新状态而不是每个协议包。必须保留事件层以支持告警、命令和回放。

## 备选

每条 WebSocket 消息直接更新所有组件；不采纳。
