# 项目愿景

## 问题

无人机实时平台的难点不是 CRUD，而是设备连接、协议演进、实时状态、告警和指令可靠性。典型风险包括消息重复、乱序、丢失、过期、网络重连、热点设备、慢客户端和数据不一致。

## 愿景

创建一个：

- 本地一条命令可启动；
- 没有真实无人机也能演示；
- 可按 DJI Cloud API 接入真实 Dock/行业无人机；
- 可扩展到机器人和其他 IoT 厂商；
- 能展示 Go 高并发、MQTT、WebSocket 和分布式可靠性的开源参考项目。

## 用户

1. 学习 Go 实时后端的开发者。
2. 验证 DJI Cloud API 集成的团队。
3. 构建设备数字孪生、告警和指令平台的 IoT 团队。
4. 需要 MQTT/WebSocket 可靠性参考实现的工程师。

## 成功标准

- 新贡献者 30 分钟内启动模拟环境；
- 端到端链路不依赖真实 DJI 密钥；
- 协议行为有自动化测试；
- 连接、队列、重试和缓存都有明确边界；
- 新型号主要通过 Capability/Method Registry 扩展。
