# 设备管理规格

## 默认列

名称、类型、型号、在线状态、电量、模式、所属 Dock、最近上报、活跃告警。

可选列：脱敏 SN、固件、经纬度、注册时间和 Capability。

## 筛选

Online/Offline/Stale/Fault、Dock、型号、设备类型、告警级别和最近上报范围。筛选状态进入 URL，并支持保存视图。

## 搜索

设备名称、SN、Dock 和模糊匹配。搜索结果高亮，不自动改变 Workspace。

## 大数据

- 服务端 Cursor；
- 表格虚拟滚动；
- 固定表头；
- Comfortable/Compact 行高；
- 更新时保留滚动位置；
- 不一次加载全部历史。

## 详情

概览、最新状态、活跃告警、最近事件、拓扑、指令历史、轨迹入口和协议诊断。

## 批量操作

MVP 只支持导出和后续标签分组，禁止批量危险指令。
