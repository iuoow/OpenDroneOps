# 空、错、加载与过期状态

## 必须区分

1. 尚无数据；
2. 筛选无结果；
3. 加载失败；
4. 数据过期。

## 空状态

### 无设备

```text
尚未接入设备
启动协议模拟器，或查看 DJI Cloud API 接入指南。
[启动模拟器指南] [接入设备]
```

### 无告警

```text
当前没有活动告警
最近同步：2 秒前
```

### 无轨迹

说明是无飞行、超出保留期、未上报位置，还是查询失败。

## 加载

App 首次使用 Skeleton；地图保持底图并显示图层 Loading；Drawer 局部加载；按钮显示内部进度；指令显示步骤，不用无限 Spinner。

## 错误

包含用户摘要、影响范围、可执行操作和 Request ID。运维权限可展开技术详情。

## Stale

降低数值强调、显示更新时间、地图半透明，并禁用或再次确认依赖实时状态的操作。

## Partial Failure

地图、列表、告警和指令独立失败。全页错误仅用于身份、Workspace 或 App Shell 无法启动。
