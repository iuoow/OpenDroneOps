# UI 验收测试

## 实时态势

- [ ] 点击地图设备打开详情并更新 URL。
- [ ] 列表与地图联动。
- [ ] 状态更新不闪烁。
- [ ] 过期状态明确。
- [ ] 断线保留数据并标记 Stale。
- [ ] 重连执行 Snapshot + Cursor。
- [ ] 慢客户端不阻塞其他客户端。

## 告警

- [ ] 同 dedup key 更新次数。
- [ ] 新告警不抢焦点。
- [ ] Acknowledge 不等于 Resolve。
- [ ] Critical 有多重视觉编码。
- [ ] Toast 不是唯一记录。

## 指令

- [ ] 明确目标、动作、参数、风险和有效期。
- [ ] 按钮文案具体。
- [ ] Publish 后不显示业务成功。
- [ ] 状态未知有说明。
- [ ] 同 Idempotency Key 不重复创建。
- [ ] MVP 无真实危险 Method。

## 轨迹

- [ ] 历史模式明显。
- [ ] 地图、图表、事件共享时间。
- [ ] 大范围查询有限制。
- [ ] 数据缺失和请求失败不同。

## 可访问性

- [ ] 键盘完成主要任务。
- [ ] 焦点不被遮挡。
- [ ] 对比度和目标尺寸通过。
- [ ] 状态不只靠颜色。
- [ ] 地图有等价列表。
- [ ] 减少动态生效。

## 性能

- [ ] Core Web Vitals 达标或记录原因。
- [ ] 1000 设备无明显冻结。
- [ ] 表格虚拟滚动。
- [ ] 高频 WS 批量渲染。
- [ ] Bundle 预算受控。
- [ ] 无长期监听器泄漏。

## Pilot

- [ ] Bridge 不可用时有 Mock 或错误页。
- [ ] 启动步骤可见。
- [ ] 触控目标至少 44px。
- [ ] 不依赖 Hover。
- [ ] 网络中断可恢复。
