# 文案与微交互

## 原则

- 先说结果，再说原因；
- 使用用户语言；
- 按钮使用动词；
- 时间使用绝对时间和相对时间；
- 不用“未知错误”作为完整信息。

## 状态

```text
在线 · 2 秒前更新
数据延迟 · 14 秒前更新
数据可能已过期 · 48 秒未更新
设备离线 · 最后上报 4 分钟前
```

## 连接

```text
实时连接正常
正在重新连接…
已连接，正在恢复实时数据
实时数据已恢复
实时连接中断，当前数据可能已过期
```

## 指令

```text
指令已进入发送队列
指令已发布，正在等待设备确认
设备已接受，正在执行
设备结果尚未确认，平台不会自动重复发送
执行失败：设备当前不满足条件
指令已超时，可查看设备事件确认最终状态
```

## 错误模板

标题说明发生了什么；正文说明影响；按钮说明可做什么；显示 Request ID。

## 数值

单位始终显示；小数位固定；缺失值用 `—` 而不是 `0`；过期数据不得继续标为“实时”。
