# 可访问性要求

## 基线

WCAG 2.2 AA。

## 对比度

- 普通文字至少 4.5:1；
- 大文字至少 3:1；
- 关键图标、边框和焦点状态有足够对比；
- 地图状态不只用颜色。

## 目标尺寸

- WCAG AA 最小目标 24×24 CSS px 或满足间距例外；
- 桌面操作建议至少 32px；
- Pilot 和触控操作建议至少 44×44px；
- 地图 Pin 可使用 Essential 例外，但必须有等价列表控件。

## 键盘与焦点

- 非地图核心任务可键盘完成；
- 合理 Tab 顺序；
- Drawer/Modal 焦点管理；
- Esc 关闭可关闭浮层；
- 不出现键盘陷阱；
- 焦点不被固定 Header/Footer/Drawer 完全遮挡；
- 关闭 Drawer 后焦点返回触发按钮。

## 动态内容

- 连接状态变化使用适当 Live Region；
- 高频遥测不逐条播报；
- Critical 告警使用受控 `aria-live`；
- Toast 可被读取但不过度重复。

## 图表与表单

图表有标题、单位、文本摘要和可下载数据；Hover 信息也能通过键盘或表格访问。表单 Label 永久可见，错误与字段关联并说明修复方法。

## 测试

axe、Playwright 键盘流程、屏幕阅读器抽测、200% 缩放、高对比、减少动态和 Pilot 触控测试。
