# 轨迹与事件回放

## 模式

实时和历史必须明显区分。历史模式固定展示：

```text
正在查看历史数据 · 2026-07-26 14:32:10
返回实时
```

## 布局

```text
┌──────────────── Map / Trajectory ─────────────────────────┐
│ Path, Direction, Alarm Points, Command Events              │
├──────────────── Playback Controls ─────────────────────────┤
│ Play Pause  1× 2× 4×  [──────── Time Slider ────────]     │
├──────────────┬──────────────┬──────────────────────────────┤
│ Altitude     │ Battery      │ Speed / State / Event List   │
└──────────────┴──────────────┴──────────────────────────────┘
```

## 同步

共享 `playbackTime`：

- 拖动时间轴同步地图、曲线和事件；
- 点击告警跳转；
- 点击图表点定位；
- 暂停显示该时刻状态；
- 时间范围写入 URL。

## 数据策略

- 初始加载摘要和降采样轨迹；
- 放大时间范围时获取细数据；
- 限制最大点数和时间范围；
- 使用稳定 Cursor；
- 大轨迹用 Web Worker 解析；
- 地图路径按缩放简化。

## 控件

Play/Pause、0.5×/1×/2×/4×、前后关键事件、时间范围、事件筛选和返回实时。

## 异常

- 无轨迹说明具体原因；
- 部分缺失使用虚线；
- 设备时间异常时提示使用服务端时间；
- 查询失败保留已加载区段并局部重试。
