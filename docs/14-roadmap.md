# 路线图

1. **Blueprint**：文档、ADR、契约、SQL、Codex 任务。
2. **Local Digital Twin**：模拟器、MQTT、状态、REST、WS、地图。
3. **Reliable Operations**：告警、Command、Outbox、审计。
4. **Real DJI**：应用凭证、Pilot 2、真实 Dock、型号能力、协议录制和 SOP。
5. **Scale**：共享订阅、多 Worker、热点隔离、WS 多实例、配额、压测。
6. **Mission/Media**：WPML、任务、对象存储、直播独立链路。
7. **Advanced**：PostGIS、地理围栏、边缘/AI、其他厂商、完成安全评审后再考虑 DRC。
