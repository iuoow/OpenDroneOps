# 路线图

1. **Blueprint**：文档、ADR、契约、SQL、Codex 任务。
2. **Local Digital Twin**：模拟器、MQTT、状态、REST、WS、地图。
3. **Reliable Operations**：告警、Command、Outbox、审计。
4. **Pilot Shell Foundation**：独立 Pilot 入口、Mock Bridge、触控/户外 UI、只读现场状态和诊断 UX；不宣称真实 DJI、飞行控制或 DRC 支持。
5. **Real DJI Gate**：在型号兼容性、应用凭证、授权硬件测试和安全 SOP 明确后，再接入 Pilot 2、真实 Dock、能力发现和协议录制。
6. **Scale**：共享订阅、多 Worker、热点隔离、WS 多实例、配额、压测。
7. **Mission/Media**：WPML、任务、对象存储、直播独立链路。
8. **Advanced**：PostGIS、地理围栏、边缘/AI、其他厂商、完成安全评审后再考虑 DRC。
