# 错误与重试

## 永久错误

无效 Topic/Schema、未知或不允许 Method、权限拒绝、前置条件失败、同幂等 Key 不同请求。不自动重试。

## 暂时错误

DB/Redis/Broker/网络超时和限流。允许有限重试。

## 状态未知

MQTT 已发布但回执未到、提交结果不确定。不得盲目重试高风险操作，先按关联 ID 查询/等待补偿。

## 策略

指数退避 + 抖动，必须有最大次数或 Deadline；操作必须幂等或有重复防护。

## Panic

边界 Recover；单条消息不能退出整个消费者；写隔离记录；不能用 Recover 隐藏持续程序错误。

## Quarantine

记录 Raw Message、错误分类、摘要、首次/最近失败、重试次数和处理状态。
