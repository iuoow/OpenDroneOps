# Definition of Done

- [ ] 范围与当前 Task 一致。
- [ ] 文档和契约同步更新。
- [ ] 新依赖有版本、许可证和理由。
- [ ] 无 `latest`、主分支或未固定依赖。
- [ ] 编译、格式、静态检查、单测通过。
- [ ] 并发组件 race test 通过。
- [ ] 失败路径有测试。
- [ ] 新 goroutine 有退出路径。
- [ ] 新队列有容量和满队列策略。
- [ ] 网络/DB/Redis 有超时。
- [ ] 重试有限、退避、抖动且幂等。
- [ ] 无秘密。
- [ ] Workspace 边界已验证。
- [ ] 指标和日志足以诊断。
- [ ] 已报告命令、结果、限制和后续任务。
